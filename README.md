# 🌤️ Weather App

A simple and responsive weather application built using **HTML, CSS, and JavaScript**. The application uses a weather API to fetch real-time weather information based on the city entered by the user.

## 🚀 Live Demo

[View Live Demo](#)

## 📌 Project Overview

The Weather App allows users to search for a city and get its current weather information.

The application sends the city name to a weather API, receives the weather data from the server, processes the JSON response using JavaScript, and displays the relevant information on the webpage.

This project was created to practice:

- HTML for webpage structure
- CSS for styling and responsive design
- JavaScript for functionality and API integration
- Fetch API for making HTTP requests
- JSON data handling
- DOM manipulation

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display temperature in Celsius
- 🌤️ Display current weather condition
- 📍 Display searched city information
- ⚡ Fetch real-time weather data using an API
- 📱 Responsive user interface
- 🎨 Clean and simple design
- ❌ Handles invalid city searches
